# Материалы для карточек Lava.top

**Подтверждено 6.10.2026 через реальный вызов API** (`gate.lava.top/api/v2/products`):
нужен всего **один товар** с двумя тарифами внутри (через переключатель
«Создать несколько тарифов») — у каждого тарифа свой `offerId`, и этот же
`offerId` работает для ОБОИХ языков: у тарифа сразу несколько цен
(RUB/USD/EUR), бэкенд просто указывает нужную валюту при создании счёта.
Отдельные RU/EN товары не нужны — изначальный план ниже с 4 карточками
устарел, Марина уже успела создать правильную структуру (1 товар, 2 тарифа)
ещё до того, как это подтвердилось.

## Что где

- `covers/cover_ru.png`, `covers/cover_en.png` — обложка (1160×464), одна на оба RU-товара и одна на оба EN-товара.
- `covers/icon.png` — квадратная иконка (512×512), универсальная. В официальной инструкции Lava.top по созданию цифрового товара отдельного поля «иконка» не нашлось (только обложка 1160×464) — сделал про запас, на случай если она нужна в другом месте интерфейса. Если увидите в форме именно такое поле — скиньте скриншот, сделаю точно под него.
- `content.md` — все тексты в порядке полей формы: Название → Описание → После оплаты → Письмо покупателю, для RU и EN.

## Обложка — размер

Подтверждён их же FAQ (faq.lava.top/article/53726): **1160×464**,
JPG/JPEG/PNG/WebP. Файлы в `covers/` уже этого размера (реально
2320×928 — вдвое больше для чёткости, но при загрузке в Lava.top итоговый
размер будет 1160×464).

## Переключатель «Цена по запросу через API»

Должен быть выключен. Бэкенд (`backend/main.py`, `create_lava_invoice`) при
создании счёта передаёт `offerId`, `currency`, `buyerLanguage` и email —
без суммы, — значит сумма берётся из цены, заданной на самом тарифе.

## Оставшиеся шаги в Lava.top

1. ~~Создать товар с двумя тарифами~~ — готово.
2. Поправить цену тарифа «10 readings» (2399 → 2499 ₽, см. выше) — или подтвердить, что 2399 ₽ верно.
3. ~~Создать API-ключ~~ — готово, уже в `backend/.env`.
4. Добавить вебхук: **Integrations → API → Add Webhook**, тип события «Успешная оплата», аутентификация **Basic**, URL — адрес бэкенда на Render + `/api/pay/lava/webhook` (добавим, когда бэкенд будет развёрнут).

## Ещё нужно проверить на стороне Lava.top (самозанятость/НПД)

При настройке аккаунта в Lava.top отдельно проверьте, включена ли для
вашего аккаунта автоматическая отправка чека по 54-ФЗ через интеграцию с
приложением «Мой налог» (для самозанятых). От этого зависит, действительно
ли чек «придёт отдельным письмом», как написано в текстах для покупателей —
если Lava.top этого не делает автоматически, формулировку в `content.md`
нужно будет поправить под то, как чек отправляется на самом деле (вручную
через «Мой налог» или иначе).

## Регенерация обложек/иконки

```
python3 gen_covers.py
```

Правьте константы в начале файла (`TITLE`, `HEADLINE`, `SUBTITLE`, `TAG`,
цвета в CSS) и запускайте заново.
