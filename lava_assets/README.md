# Материалы для 6 карточек Lava.top

Готово для создания продуктов в Lava.top (Dashboard → Products → Create):
pack3 / pack10 / pack15, отдельно RU и EN — 6 карточек.

## Что где

- `covers/pack{3,10,15}_{ru,en}.png` — обложка для каждой карточки (6 файлов).
- `content.md` — для каждой карточки: краткое описание, сообщение после
  оплаты и текст письма покупателю (тема + текст), RU и EN.

## Важная оговорка про обложки

Официальная страница с требованиями к размеру обложки на Lava.top
(faq.lava.top) при подготовке этих файлов отдавала ошибку 403 при любой
попытке её открыть, поэтому точный требуемый размер подтвердить не
удалось. Обложки сделаны 1200×630 (в 2 раза больше по пикселям для
чёткости) — это стандартный размер обложки/превью, который принимают
почти все подобные платформы, и в редакторе Lava.top обычно можно
обрезать/подогнать загруженное изображение под нужный формат. Если при
загрузке Lava.top укажет другие пропорции — пересоберу обложки под
точный размер (скрипт `gen_covers.py` это позволяет за одну правку).

## Порядок действий в Lava.top

1. Создать 6 продуктов (по одному на каждую карточку выше).
2. Для каждого: загрузить обложку, вставить краткое описание, сообщение
   после оплаты и письмо покупателю из `content.md`, указать цену
   (399 / 999 / 1399 ₽ для RU, $4.99 / $11.99 / $15.99 для EN).
3. Скопировать `offerId` (UUID) каждого продукта и вписать в
   `backend/.env` в соответствующую переменную:
   `LAVA_OFFER_PACK{3,10,15}_{RU,EN}`.
4. В Dashboard → Integrations → API — создать API-ключ и webhook-ключ,
   вписать в `LAVA_API_KEY` / `LAVA_WEBHOOK_SECRET` там же.
5. Указать адрес вебхука в Lava.top: `https://<ваш домен>/api/pay/lava/webhook`.

## Ещё нужно проверить на стороне Lava.top (самозанятость/НПД)

При настройке аккаунта в Lava.top отдельно проверьте, включена ли для
вашего аккаунта автоматическая отправка чека по 54-ФЗ через
интеграцию с приложением «Мой налог» (для самозанятых). От этого
зависит, действительно ли чек «придёт отдельным письмом», как написано
в текстах для покупателей — если Lava.top этого не делает автоматически,
формулировку в `content.md` нужно будет поправить под то, как чек
отправляется на самом деле (вручную через «Мой налог» или иначе).

## Регенерация обложек

```
python3 gen_covers.py
```

Меняет размер/цвета/тексты — правьте константы в начале файла
(`PACKS`, `TITLE`, `SUBTITLE`, цвета в CSS) и запускайте заново.
