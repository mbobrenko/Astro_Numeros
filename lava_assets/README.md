# Материалы для 6 карточек Lava.top

Готово для создания продуктов в Lava.top (Dashboard → Products → Create):
pack3 / pack10 / pack15, отдельно RU и EN — 6 карточек.

## Что где

- `covers/pack{3,10,15}_{ru,en}.png` — обложка для каждой карточки (6 файлов), уже в размере, который требует Lava.top.
- `content.md` — для каждой карточки, в порядке полей формы Lava.top:
  Название продукта → Описание продукта → После оплаты → Письмо покупателю
  (тема + текст), RU и EN.

## Обложки

Размер подтверждён их же FAQ (faq.lava.top/article/53726): **1160×464**,
JPG/JPEG/PNG/WebP. Файлы в `covers/` уже ровно этого размера (реально
2320×928 — вдвое больше для чёткости, но пропорция и итоговый размер при
загрузке в Lava.top будут 1160×464).

## Цена и переключатель «Цена по запросу через API»

Введите цену вручную в поле цены на Lava.top:
- RU: 399 ₽ / 999 ₽ / 1399 ₽
- EN: $5.99 / $11.99 / $15.99 (цену пакета из 3 разборов пришлось поднять
  с изначальных $4.99 до $5.99 — у Lava.top минимальная цена товара $5)

Переключатель **«Цена по запросу через API»** выключите. Наш бэкенд
(`backend/main.py`, `create_lava_invoice`) при создании счёта передаёт
только `offerId`, `currency`, `buyerLanguage` и email — без суммы, — значит
сумма должна браться из цены, заданной в самой карточке продукта.

## Порядок действий в Lava.top

1. Создать 6 продуктов (по одному на каждую карточку выше), цифровой продукт.
2. Для каждого: загрузить обложку из `covers/`, вставить название и
   описание, заполнить «После оплаты» и (по желанию) «Письмо покупателю»
   из `content.md`, указать цену как выше, выключить «Цена по запросу
   через API».
3. Скопировать `offerId` (UUID) каждого продукта и вписать в
   `backend/.env` в соответствующую переменную:
   `LAVA_OFFER_PACK{3,10,15}_{RU,EN}`.
4. В Dashboard → Integrations → API — создать API-ключ и webhook-ключ,
   вписать в `LAVA_API_KEY` / `LAVA_WEBHOOK_SECRET` там же. Один и тот же
   API-ключ/webhook-ключ действует на весь аккаунт — подходит для всех 6
   карточек (и для любых других, не связанных с этим, продуктов тоже).
5. Указать адрес вебхука в Lava.top: `https://<ваш домен>/api/pay/lava/webhook`.

## Ещё нужно проверить на стороне Lava.top (самозанятость/НПД)

При настройке аккаунта в Lava.top отдельно проверьте, включена ли для
вашего аккаунта автоматическая отправка чека по 54-ФЗ через
интеграцию с приложением «Мой налог» (для самозанятых). От этого
зависит, действительно ли чек «придёт отдельным письмом», как написано
в текстах для покупателей — если Lava.top этого не делает автоматически,
формулировку в `content.md` нужно будет поправить под то, как чек
отправляется на самом деле (вручную через «Мой налог» или иначе).

## Регенерация обложек

```
python3 gen_covers.py
```

Меняет размер/цвета/тексты — правьте константы в начале файла
(`PACKS`, `TITLE`, `SUBTITLE`, цвета в CSS) и запускайте заново.
