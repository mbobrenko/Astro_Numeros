# Материалы для карточек Lava.top

Готово для создания продуктов в Lava.top (Dashboard → Products → Create):
4 карточки (pack3 / pack10 × RU / EN), но тексты и картинки —
универсальные (один и тот же текст/обложка на оба пакета одного языка),
различается только название товара и цена.

## Что где

- `covers/cover_ru.png`, `covers/cover_en.png` — обложка (1160×464), одна на оба RU-товара и одна на оба EN-товара.
- `covers/icon.png` — квадратная иконка (512×512), универсальная. В официальной инструкции Lava.top по созданию цифрового товара отдельного поля «иконка» не нашлось (только обложка 1160×464) — сделал про запас, на случай если она нужна в другом месте интерфейса. Если увидите в форме именно такое поле — скиньте скриншот, сделаю точно под него.
- `content.md` — все тексты в порядке полей формы: Название → Описание → После оплаты → Письмо покупателю, для RU и EN.

## Обложка — размер

Подтверждён их же FAQ (faq.lava.top/article/53726): **1160×464**,
JPG/JPEG/PNG/WebP. Файлы в `covers/` уже этого размера (реально
2320×928 — вдвое больше для чёткости, но при загрузке в Lava.top итоговый
размер будет 1160×464).

## Цена и переключатель «Цена по запросу через API»

Введите цену вручную в поле цены на Lava.top:
- RU: 999 ₽ / 2499 ₽ (pack3 / pack10)
- EN: $14.99 / $34.99 (то же соотношение к рублю, что вы задали для RU —
  это моё предложение по курсу, проверьте и поправьте если нужно; оба
  выше минимальной цены Lava.top в $5 за товар)

Тариф на 15 разборов убрали по вашему решению — остались только 3 и 10,
после окончания пакета можно докупить ещё в любой момент.

Переключатель **«Цена по запросу через API»** выключите. Бэкенд
(`backend/main.py`, `create_lava_invoice`) при создании счёта передаёт
только `offerId`, `currency`, `buyerLanguage` и email — без суммы, — значит
сумма должна браться из цены, заданной в самой карточке продукта.

## Порядок действий в Lava.top

1. Создать 4 продукта (цифровой продукт), по одному на pack3/10 × RU/EN.
2. Для каждого: загрузить `cover_ru.png` или `cover_en.png` (в зависимости от языка), название и цену — свои для каждого товара (см. `content.md`), описание/после оплаты/письмо покупателю — одинаковые для обоих товаров одного языка (тоже из `content.md`), выключить «Цена по запросу через API».
3. Скопировать `offerId` (UUID) каждого продукта и вписать в
   `backend/.env` в соответствующую переменную:
   `LAVA_OFFER_PACK{3,10}_{RU,EN}`.
4. В Dashboard → Integrations → API — создать API-ключ и webhook-ключ,
   вписать в `LAVA_API_KEY` / `LAVA_WEBHOOK_SECRET` там же. Один и тот же
   ключ действует на весь аккаунт — подходит для всех 4 карточек (и для
   любых других, не связанных с этим, продуктов тоже).
5. Указать адрес вебхука в Lava.top: `https://<ваш домен>/api/pay/lava/webhook`.

## Ещё нужно проверить на стороне Lava.top (самозанятость/НПД)

При настройке аккаунта в Lava.top отдельно проверьте, включена ли для
вашего аккаунта автоматическая отправка чека по 54-ФЗ через интеграцию с
приложением «Мой налог» (для самозанятых). От этого зависит, действительно
ли чек «придёт отдельным письмом», как написано в текстах для покупателей —
если Lava.top этого не делает автоматически, формулировку в `content.md`
нужно будет поправить под то, как чек отправляется на самом деле (вручную
через «Мой налог» или иначе).

## Регенерация обложек/иконки

```
python3 gen_covers.py
```

Правьте константы в начале файла (`TITLE`, `HEADLINE`, `SUBTITLE`, `TAG`,
цвета в CSS) и запускайте заново.
